# 프롬프트 꾸러미 5 (손바닥 · 팔)

- H1·H2: 손바닥이 앞으로 보이는 팔(만세, 손 흔들기). 기본 린넨 옷 기준. **먼저 이것만 받아도 돼요.**
- H3: 앞으로 내미는 팔(건네기, 쓰다듬기). H4: 손 모양 8종. H5: 다른 옷용(선택).
- 모든 프롬프트에 refs 그림을 같이 첨부하세요. 마젠타 배경, 부품끼리 닿지 않게, 글자 금지.
- 받은 그림은 스튜디오 「만들 것」의 「손바닥이 앞으로 보이는 팔」 칸에 올려 저장하고 내보내기로 주세요.
- 걷기 때 팔 흔들기와 몸 앞/뒤 겹침은 그림 없이 스튜디오 「캐릭터 맞추기」→ 걷기 팔에서 바로 조절돼요.
