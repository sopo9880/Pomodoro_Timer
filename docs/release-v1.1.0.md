# v1.1.0 릴리스 체크리스트

릴리스는 사람이 직접 발행해요. 아래가 끝난 뒤에 올려요.

## 올리기 전
- [ ] 이 작업의 PR을 `main`에 합치고, 배포(GitHub Pages)가 끝났는지 확인.
- [ ] 배포된 사이트를 휴대폰(안드로이드 1대, 아이폰 1대)에서 열기.
  - [ ] 걷기, 카메라 따라가기, 목 위치, 옷 갈아입기(머리·옷·신발·모자) 모습.
  - [ ] 한 프레임이 30ms를 넘지 않는지(끊김 없이 부드러운지).
  - [ ] 집중 완료 연출이 5초 안에 끝나고 설정에서 꺼지는지.
  - [ ] 소리(우편함 딩, 풍경, 우물)가 나고, 집중 중에는 조용한지.
  - [ ] 일지의 "정원 일기 공유하기"가 공유 창을 여는지.
- [ ] 예전 저장 파일(이전 버전에서 쓰던 정원)을 열어 아무것도 사라지지 않았는지.
- [ ] 앱을 한 번 닫았다 열어 새 버전으로 바뀌는지(서비스 워커 캐시 `v32` 이상).
- [ ] 뒷모습에서 아래팔이 치마 뒤에 가려지는 것이 의도인지 결정(손을 보이게 하려면 해당 팔 부품의 z값을 0으로).

## 발행
1. GitHub 저장소 → Releases → Draft a new release.
2. 태그 `v1.1.0`, 대상 `main`의 합친 커밋.
3. 제목 "v1.1.0 — 옷 갈아입기와 살아 있는 정원".
4. 설명(아래 요약을 붙여 넣기).
5. Publish.

## 설명 초안
- 옷 갈아입기: 머리 4종, 옷 4종, 신발 3종, 모자 4종이 정원 캐릭터에 그대로 입혀져요.
- 정원이 더 풍성해졌어요: 지역 꾸미기 소품, 밤 조명, 부드러운 길 경계, 물가와 바닥 꾸밈, 방향이 있는 가구 회전.
- 손맛: 집중 완료 연출(끌 수 있어요), 걷는 먼지, 동료 말풍선, 작은 소리, 집중 중 조용한 화면.
- 오래 쓰는 즐거움: 도감 힌트와 처음 만난 날, 조건으로 만나는 희귀 생물, 학기 기념물, 벌 없는 복귀 인사, 주간 리듬, 공유 그림.
- 저장 형식과 집중 보상 계산은 그대로예요. 예전 정원은 그대로 열려요.

## 아직 포함되지 않은 것
- 벤치·모닥불 앞에 앉기, 그네 타기, 상호작용 포즈(그림 재작업 중).
- 만세 팔.
