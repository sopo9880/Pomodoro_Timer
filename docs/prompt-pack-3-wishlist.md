# 프롬프트 꾸러미 3 — 그림 요청 목록 (4K 필수 + 4L·4M·4N 선택)

## 공통 규칙 (지금까지 꾸러미와 같음)
- 배경은 **단색 마젠타**(자르기 도구 `tools/keyer.py`가 이 색을 지움). 부품끼리 **서로 닿지 않게** 띄워서 배치(자동 분리).
- 그림자·바닥·글자·테두리 틀 없음. 분홍 디테일은 부품 안쪽이면 괜찮음.
- **기준 캐릭터와 같은 얼굴·체형·화풍·비율.** 기준은 `assets/art/avatar/{front,side,back,boots}/`의 현재 부품.
- 한 장에 한 묶음. 파일명 끝에 해시가 있으면 내가 알아서 매칭함.

## A. 4K 필수 (옷 갈아입기) — 시트 11장

현재 기본 옷(린넨), 기본 머리(자연), 신발(여행)은 이미 있음. **빠진 변형**만 요청.

### A1. 머리 3종 (시트 3장) — 밤색 단발(`hair-chestnut`), 은빛(`hair-silver`), 꽃빛(`hair-bloom`)
한 시트에 아래 6부품 (기본 머리와 같은 크기감):
1. 정면 머리(얼굴 포함, 앞머리) — 기준 `front/head.webp` (190×166)
2. 정면 뒷머리 — 기준 `front/hair_back.webp`
3. 측면 머리 — 기준 `side/head.webp`
4. 측면 머리 눈 감은 버전 — 기준 `side/head_blink.webp`
5. 측면 뒷머리 — 기준 `side/hair_back.webp`
6. 뒷모습 머리 — 기준 `back/head.webp`
- 밤색 단발은 어깨 위 길이(뒷머리 부품이 짧아야 함).

### A2. 옷 3종 (시트 3장) — 숲(`outfit-forest`), 정원(`outfit-garden`), 별빛(`outfit-starlight`, 망토 없음)
한 시트에 아래 12부품 (기본 옷과 같은 크기·관절 위치):
- 정면: 몸통(140×213 기준), 치마(396×248), 왼소매, 오른소매
- 측면: 몸통, 몸통 대체(`torso_alt`), 치마, 가까운 팔 소매, 먼 팔 소매
- 후면: 몸통, 치마, 왼소매, 오른소매
- 색·무늬·자수만 다르게. 실루엣과 길이는 기본 옷과 같게(치마 아래 다리가 보이는 구조 유지).

### A3. 신발 2종 (시트 2장) — 부츠(`shoes-boots`), 하늘색(`shoes-sky`)
한 시트에 6부품: 정면 좌·우, 후면 좌·우, 측면 가까운·먼 쪽. 기준 `avatar/boots/*.webp`(정면은 109×401, 다리 포함 길이).

### A4. 모자 3종 (시트 3장) — 밀짚(`hat-straw`), 꽃(`hat-flower`), 별(`hat-star`)
한 시트에 4부품: 정면, 측면, 후면, 그리고 머리 **뒤에 깔리는** 챙 부분(있을 때만). 머리 부품 위에 얹히는 크기로.

## B. 4L 월드 다듬기 (선택, 시트 약 6장)
1. 바닥 경계 섞기: 풀↔흙길, 풀↔돌길, 풀↔물가, 흙↔돌 **가장자리 전환 타일** (변 4 + 모서리 4, 종류별)
2. 물가: 갈대, 연잎, 물결 링, 반짝임 (각 3~4 변형)
3. 바닥 반복 무늬 숨기기: 꽃무리, 자갈, 풀 뭉치, 낙엽 더미 (투명 데칼, 각 4~6)
4. 지역 꾸미기: 6개 지역 × 소품 5개 (숲·작업실·온실·연못·별빛언덕·중앙정원). 아직 안 쓴 소품 55개가 있으니 겹치지 않게
5. 밤 조명: 랜턴/모닥불/창문 빛 번짐(부드러운 원형 글로우 3종), 반딧불 군집

## C. 4M 게임 손맛 (선택, 시트 약 3장)
1. 만세 팔(앞·측·뒤, 4J에서 이월)
2. 걷기 흙먼지 4프레임, 발자국 2종, 풀 스침 2종
3. 집중 완료 연출 추가: 꽃잎 비, 별가루, 빛줄기 (기존 `ui/fx/celebration` 12개와 같은 스타일)

## D. 4N 오래 쓰는 장치 (선택, 시트 약 3장)
1. 조건으로 만나는 희귀 생물 4종 (기존 14종과 같은 크기/화풍, 걷기 2프레임씩)
2. 학기 기념물 4종 (석비·나무 표지·꽃아치 등, 64px 랜드마크 크기)
3. 요일 리듬 배지 7개, 공유 카드 장식 틀(글자 없음) 2종

## 우선순위
**A(11장)만 있어도 4K는 끝낼 수 있음.** B·C·D는 지금 받으면 후속 단계에서 바로 쓰고, 안 받아도 막히지 않음.
