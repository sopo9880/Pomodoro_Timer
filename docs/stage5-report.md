# 5단계 점검 보고 (안정화 · 릴리스 준비)

측정은 모두 헤드리스 Chromium(데스크톱)에서 했고, 휴대폰 느낌은 CPU를 4배 늦춰 흉내 냈어요. **실제 안드로이드·아이폰 확인은 아직 못 했어요.**
다시 재려면 저장소 루트에서 `python3 -m http.server 8766`을 켜고 `NODE_PATH=$(npm root -g) node tools/<스크립트>`를 돌리면 돼요.

## 성능 (`tools/perf-check.js`, 80개 설치물 + 동료 6마리 + 모든 구역 열림)

| 상황 | 그리기 시간 (p50 / p95) |
|---|---|
| 데스크톱, 기본 확대 | 0.4 ms / 0.9 ms |
| CPU 4배 느리게, 기본 확대 | 1.2 ms / 3.2 ms |
| CPU 4배 느리게, 멀리 보기 | 2.1 ms / 5.7 ms |
| CPU 4배 느리게, 가까이 보기 | 0.8 ms / 2.9 ms |

- 이 값은 **자바스크립트가 그리기 명령을 내리는 시간**이에요. 화면에 칠하는 그래픽 처리 시간은 들어 있지 않아서, 목표(휴대폰에서 한 프레임 30ms 이하)는 **실기기로 확인해야** 해요.
- 걸어서 구역 경계를 넘어도(240프레임) 가장 느린 프레임이 1.2ms였어요. 화면 밖 한 칸 바깥 구역을 한가한 순간에 미리 구워 두기 때문이에요.
- 확대·축소를 크게 바꾸는 순간에는 한두 프레임이 20~40ms(CPU 4배 늦춤에서는 80~160ms)로 튀어요. 선명도 단계가 바뀌며 바닥을 새로 굽기 때문이에요.

## 첫 방문 (`tools/first-visit-check.js`, 캐시 없음, CPU 4배 느리게)

| 네트워크 | 질감 있는 정원이 보이기까지 |
|---|---|
| 빠른 4G (9 Mbps, 60 ms) | 약 3.1~3.2초 (고치기 전 4.1초) |
| 느린 4G (1.6 Mbps, 150 ms) | 약 13초 (약 1MB를 받는 시간이 대부분) |

- 목표 "첫 방문 3초 안"은 빠른 4G에서 **간신히** 맞고, 느린 4G에서는 못 맞아요.
- 이번에 한 개선: 모든 모듈을 `modulepreload`로 미리 불러 의존 사슬을 없앴고(테스트로 계속 지켜요), 첫 화면이 뜨기 전에는 꾸미기 소품과 바닥 합치기를 미뤄요.
- 더 줄이려면: 첫 화면에 필요한 그림만 먼저 받기, 150KB 글꼴 CSS 쪼개기.

## 메모리 (모든 구역을 한 번씩 돌아본 긴 사용 기준 추정)

| 항목 | 크기 |
|---|---|
| 풀어 둔 그림 | 약 109MB |
| 바닥 합친 캔버스 (상한) | 40MB |
| 자바스크립트 | 약 10MB |
| **합계** | **약 158MB** |

- 목표 150MB 이하는 **최악의 경우(모든 구역을 한 세션에 방문)에는 살짝 넘어요.** 한두 구역만 쓰는 보통 사용은 이보다 훨씬 낮아요.
- 더 줄이려면: 떠난 구역의 그림을 내려놓기, 바닥 질감 해상도 낮추기.

## 타이머 신뢰성
- 이번 작업은 타이머 계산을 건드리지 않았어요. 타이머는 집중이 끝날 때 이벤트를 한 번 내보낼 뿐이에요.
- 기존 타이머·집중 시간 테스트(`focus-core`, `game-shell` 등)가 그대로 통과해요. 전체 테스트 163개.
- 백그라운드 탭, 화면 잠금, 여러 탭에서의 실제 동작은 브라우저에서 사람이 확인해야 해요.

## 접근성
- 정원 안내 문구는 읽어 주는 영역(`role="status"`, `aria-live="polite"`)에 나와요. 설치물을 눌렀을 때 문구, 복귀 인사, 도감 기록이 여기로 읽혀요.
- 모든 새 움직임(집중 완료 연출, 먼지, 물결, 반짝임, 모닥불 불꽃, 풍경, 말풍선 흔들림)은 **동작 줄이기** 설정에서 멈추거나 사라져요. 집중 중에도 멈춰요.
- 꾸밈용 그림(요일 배지, 말풍선)은 `alt=""`로 읽기에서 빼 뒀고, 정보는 글로도 나와요.
- 집중 완료 연출은 설정에서 끌 수 있어요. 소리는 기존 알림음 스위치와 크기를 따라요.
- 확인 못 한 것: 화면 낭독기로 실제 듣기, 글자 대비 측정.

## 화면 비교 (`tools/visual-check.js`)
- 장면 6개(중앙 낮, 연못 낮, 숲 낮, 별빛 밤, 공방 낮, 옷+모자 입은 캐릭터)를 고정 시각으로 그려 `tests/visual/*.png`와 비교해요. 같은 코드로 두 번 돌리면 0.00% 차이예요.
- 일부러 모양을 바꾼 뒤에는 `--update`로 새 기준을 저장해요. 이 비교는 CI에는 아직 넣지 않았어요(브라우저가 필요해서).
