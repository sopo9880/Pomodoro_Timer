# 설치물 상호작용 계획 (확정 사항)

## 결정
- 휴식 타이머가 시작되면 아바타가 가까운 빈 자리(벤치 등)로 자동으로 가서 앉는다. **기본 켜짐, 설정에서 끌 수 있음.**
- 우편함 문구는 Claude가 쓴다 (아래 `우편함 문구`).

## 단계
1. 앉기·쉬기 (4M 휴식 앉기와 합침): 설치물의 "사용 자리(slots: 위치 오프셋, 바라보는 방향, 동작)"를 종류별 데이터로 정의. 회전하면 자리도 같이 돈다.
2. 동료가 설치물을 사용 (벤치에서 낮잠, 테이블에서 독서). 점유는 저장하지 않고 화면에서만 계산.
3. 한 번 누르면 반응: 모닥불(따뜻함), 그네(흔들림), 우편함(문구), 우물·풍경·물그릇(소리·반짝임·한 줄).
4. 집중 중에는 걸어가는 상호작용 금지, 반응 문구도 숨김.

저장 형식(`bloomodoro-state-v3`, 정원 스키마 2)과 집중 보상 계산은 바꾸지 않는다.

## 우편함 문구 (초안)
- 오늘도 와 줘서 고마워요.
- 편지는 없지만, 우편함이 반짝였어요.
- 천천히 해도 괜찮아요. 정원은 기다려요.
- 물 한 모금 마시고 오세요.
- 어제의 당신이 심은 씨앗이 자라고 있어요.
- 쉬는 것도 일의 일부예요.
- 동료들이 안부를 전해 달래요.
- 오늘의 한 걸음이면 충분해요.
- 창문을 열고 바람을 한 번 느껴 보세요.
- 돌아오신 걸 환영해요. 아무것도 시들지 않았어요.
